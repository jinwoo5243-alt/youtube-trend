# 유튜브 트렌딩 수집 (웹 공개용)

유튜브 인기 카테고리 + 드라마 인급동을 정리한 HTML 리포트입니다.
이 폴더에는 **공개해도 되는 `index.html` 하나만** 둡니다.
(수집 코드·OAuth 토큰·API 키 등은 이 폴더에 없음 → 깃허브에 올라가지 않음)

## 새로 수집한 내용으로 갱신하기

1. 먼저 수집기를 실행해 최신 HTML을 만듭니다: `..\수집기\실행.bat`
2. 이 폴더에서 `갱신.bat` 실행 → 최신 HTML을 `index.html`로 복사하고 깃허브에 올립니다.

## GitHub Pages로 웹페이지처럼 보기 (선택)

저장소 → Settings → Pages → Branch를 `main` / `/ (root)`로 지정하면
`https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.
