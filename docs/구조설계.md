```
├─ [2] 실시간 인기 영상  realtime

│    │    └─ 유형별 TOP (숏폼/롱폼)
│    ├─ 조회수 TOP 실시간 영상 (영상 카드 그리드)
│    └─ 채널 신호 TOP (일일 조회수 반응 큰 채널)
│
├─ [3] HOT 채널 파인더  channels
│    ├─ 툴바: 고급 필터 설정 · 카테고리 필터 · 정렬
│    ├─ 검색: 채널명/핸들 검색
│    ├─ 상태바: 발굴된 채널 수 · 통계 조회 무제한
│    └─ 채널 테이블 (채널정보 · 구독자 · 최근 업로드 · 영상수 · 조회수 증감 · 예상수익 · 등급)

└─ (공용 모달)
     ├─ 고급 필터  advanced-filter
     │    └─ 조회수 증감 기준 · 정렬 기준 · 구독자 범위 · 영상 수 범위 · 국가 · 등급(S~F)
     └─ 카테고리 필터  category-filter
          └─ 채널 수 많은 순 다중 선택 (초기화 / 필터 적용)
```

## 2. 공통 레이아웃 & 네비게이션

- **글로벌 헤더**: 로고 아이콘 + 페이지 타이틀 + 서브 설명 + 탭 네비게이션(키워드 / 실시간 영상 / 채널 파인더)
- **라우팅**: 해시 라우팅 권장 (`#/keywords`, `#/realtime`, `#/channels`) — 단일 셸에서 탭 전환, 또는 페이지 분리
- **다크 테마 기반** (스크린샷 전부 다크). 현재 `index.html`의 CSS 변수(`--bg/--card/--fg/--accent`) 방식 그대로 확장
- **반응형**: 카드 그리드는 `auto-fill minmax()`, 모달은 모바일 풀스크린화

## 3. 페이지별 상세 구조

### 3.1 주간 인기 키워드 `keywords`

**목적**: YouTube Shorts 조회수 기준으로 뜨는 키워드와 일별 소비량 흐름 파악

| 섹션 | 구성 요소 |
|---|---|
| 헤더 | 아이콘 · "주간 인기 키워드" · 서브설명 |
| 모드 토글 | 🔥 주간 Top 100 / 🔖 내 키워드 |
| 테이블 헤더 | 기간 토글(24시간/7일) · 가나다 전체 보기 · "7일 조회수 기준" 뱃지 |
| 랭킹 테이블 | 순위 · 키워드 · 7일 소비량 · 일별 흐름(스파크라인) · 수집 상태 |

**테이블 행(키워드) 1건 구성**
- 순위 뱃지 (1, 2, 3 …)
- 키워드명 + 외부 링크 아이콘(↗ YouTube 검색)
- 소비량 (예: `1.3억회`)
- **스파크라인**: 최근 최대 14일치 꺾은선 + 시작일/시작값 · 증감률(▲+112.2% / ▼-21.3%) · 종료일/종료값
- 수집 상태: `수집 완료` 뱃지 + 마지막 업데이트 시각(한국시간)

**인터랙션**: 키워드 클릭 → 상세 뷰(24h·7d 수집 영상 목록 + 세부 분석)

---

### 3.2 실시간 인기 영상 `realtime`

**목적**: 지금 가장 빠르게 뜨는 영상을 국가·유형별로 실시간 확인

**필터 바**: `전체 / KR 한국 / US 미국 / JP 일본` · `전체 / 롱폼 / 숏폼` · (우측) 인기 영상 수 표시

**(A) 홈 대시보드**
- **KPI 타일**: 전체 영상 · 숏폼 · 롱폼 · 최고 조회수
- **국가별 실시간 랭킹**: KR/US/JP 카드 — 대표 썸네일, 숏폼/롱폼 개수
- **유형별 TOP**: 숏폼 / 롱폼 블록 (개수 + 대표 썸네일)

**(B) 조회수 TOP 실시간 영상** — 영상 카드 그리드
- 순위 뱃지 · 국가 태그 · 유형 태그(롱폼/숏폼)
- 썸네일 · 제목(2줄 clamp)
- 채널명 · 구독자 · 업로드 경과시간
- 총 조회수 · **일일 조회수 +증감(↗)**

**(C) 채널 신호 TOP**
- "채널 일일 조회수 반응이 큰 순서" — 채널 카드: 순위 · 채널명 · 대표 영상 제목 · 구독자 · 일일 조회수 증감

---

### 3.3 HOT 채널 파인더 `channels`

**목적**: 구독자 대비 조회수가 폭발 성장하는 "숨은 보석" 채널 발굴

**툴바**: `⚙ 고급 필터 설정` · `🏷 카테고리 필터` · `정렬: 총 조회수순`
**검색바**: [채널명 ▾ 드롭다운] + 검색어 입력 + 🔍 / (우측) 발굴된 채널 수 · 통계 조회 무제한

**채널 테이블 컬럼**

| 컬럼 | 내용 |
|---|---|
| 채널 정보 | 썸네일 · 채널명 · **등급 뱃지(S~F)** · @핸들 · 카테고리 태그 |
| 구독자 | 예: 3.2억 |
| 최근 업로드 콘텐츠 | 썸네일 5개 가로 나열 |
| 영상 수 | 예: 2.7만 |
| 조회수 증감 | 일일 조회수 +증감(↗) · **예상 수익(원)** · 📊 통계 · ♡ 즐겨찾기 |

## 5. 공용 필터 사양

### 5.1 고급 필터 (`advanced-filter`)
| 항목 | 값/타입 | 기본 |
|---|---|---|
| 조회수 증감 기준 | 없음 / 1일 / 48시간 / 7일 / 30일 | 없음 |
| 정렬 기준 | 총 조회수 / 구독자 | 총 조회수 |
| 구독자 범위 | 최소~최대 (숫자) | 비움 |
| 영상 수 범위 | 최소~최대 (숫자) | 비움 |
| 국가 | KR / US / JP / 그 외 (다중) | 전체 |
| 등급 | S A B C D F (다중) | 전체 |

> ⚠️ 안내 문구(UI에 노출): "YouTube API 오류로 간혹 오늘 총조회수가 어제와 같이 갱신 안 된 상태로 전송될 수 있음 → 48시간 이상 지표 권장."
> 규칙: 기간(증감 기준) 선택 시 정렬이 자동으로 '조회수 증감 기준'으로 전환.

### 5.2 카테고리 필터 (`category-filter`)
- 다중 선택, **채널 수 많은 순** 정렬
- 예: 라이프스타일(1,077,314) · 엔터테인먼트(735,415) · 영화/애니(364,636) · 음악(336,975) · 비디오 게임 문화(281,402) … 클래식 음악(4,883)
- 하단: `초기화` / `필터 적용`

## 7. 등급(S~F) 산정 로직 — 제안

"구독자 대비 조회수 폭발" = **일일 조회수 증가 ÷ 구독자 수** 비율을 핵심 지표로.

```
ratio = dailyViewDelta / max(subscriberCount, 1)
S: ratio ≥ 0.5     (구독자의 50%+ 가 하루 조회 증가)
A: 0.2 ~ 0.5
B: 0.1 ~ 0.2
C: 0.05 ~ 0.1
D: 0.02 ~ 0.05
F: < 0.02          (대형 채널 등 성장률 둔화)
```
> 임계값은 실제 데이터 분포 보고 조정. 예상 수익(원)은 조회수 × CPM 가정으로 추정.

## 8. 파일 / 코드 구조 제안

기존 운영 패턴(수집기 → JSON → 웹앱이 읽기)과 동일하게 구성.

```
웹공개/
├─ index.html              # 통합 셸(헤더+탭) 또는 랜딩
├─ pages/
│   ├─ keywords.html
│   ├─ realtime.html
│   └─ channels.html
├─ assets/
│   ├─ css/app.css         # 공통 테마/컴포넌트
│   └─ js/
│       ├─ common.js       # 헤더·포맷터(억/만, 시각)·DeltaValue
│       ├─ modal.js        # 고급/카테고리 필터 모달
│       ├─ sparkline.js    # 미니 차트
│       ├─ keywords.js
│       ├─ realtime.js
│       └─ channels.js
└─ data/                   # 수집기가 생성 (웹앱은 읽기만)
    ├─ keywords_7d.json
    ├─ keywords_24h.json
    ├─ realtime_latest.json
    ├─ channels.json
    └─ categories.json
```

> GitHub Pages 정적 호스팅과 호환. 민감키는 프런트에 두지 않고, 수집기가 서버/로컬에서 JSON만 생성해 올리는 구조 유지.

## 9. 구현 로드맵(제안)

1. **공통 셸 + 테마 + 라우팅** (헤더/탭, CSS 변수, 해시 라우팅)
2. **공용 컴포넌트** (Modal, Tag, DeltaValue, Sparkline, GradeBadge)
3. **실시간 인기 영상** — 기존 `index.html` 자산 재활용이 가장 쉬움(카드 그리드 이미 존재)
4. **주간 인기 키워드** — 테이블 + 스파크라인 + 수집상태
5. **HOT 채널 파인더** — 테이블 + 고급/카테고리 필터 + 등급 로직
6. **데이터 계약 확정** — 위 6장 JSON 스키마대로 수집기 출력 맞추기
